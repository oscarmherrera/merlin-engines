# RTX 8000 long-context attention, direct measurements

The pinned Prism CUDA attention dispatcher uses an eight-head MMA group for the Bonsai 2 27B model's 6:1 GQA, 256-dimensional heads. Two group columns are masked. An isolated SM75 candidate selects the existing two-head MMA specialization for this geometry; all other head geometries and devices retain the pinned selection. The repository overlay also limits this selection to query batches above eight, leaving decode batches 1/2/4/8 alone. The reduced padded work is a plausible mechanism, not an isolated hardware-counter attribution: the two-head mapping can reread K/V across three groups.

The RTX 8000 stock endpoint remained unchanged. All measurements used direct CUDA runtimes with Q8/Q8 KV, no calibration, and no containers. Robot `running_runs.total` was zero before each build or GPU load. A direct `test-backend-ops` performance case used 24 query heads, four KV heads, head dimension 256 and a 2,048-query prefill chunk. The same staged test binary was run with the stock and candidate CUDA libraries. These are one matched benchmark per case, with the harness's internal graph replays:

| KV depth | Stock Q8 attention | Two-head Q8 attention | Time reduction |
|---:|---:|---:|---:|
| 65,536 | 137.151 ms | 101.496 ms | 26.0% |
| 225,280 | 473.630 ms | 346.612 ms | 26.8% |

At 65,536 KV, F16/F16 took 135.205 ms stock and 100.011 ms with the candidate. The near-tie between stock Q8 and F16 at this depth shows that Q8-to-F16 conversion is not the dominant long-context cost. The candidate passed both Q8 and F16 CPU-reference attention cases at 6:1 GQA, 512 KV tokens and 16 query tokens (2/2). The 225K performance case was not CPU-reference checked.

One `llama-bench` direct model run used 225,000 prompt tokens and ten generated tokens, Q8/Q8 KV, batch 4,096, microbatch 2,048, flash attention and CUDA operation tracing. It completed in 602.369 seconds. The saved stock Prism trace used 226,000 prompt tokens, so whole-run wall times are **not** an exact pair. The first 109 full 2,048-token prefill chunks have the same depth and graph shapes, and are compared below:

| First 109 full chunks | Stock Prism | Two-head candidate | Time reduction |
|---|---:|---:|---:|
| All traced operations | 696.759 s | 583.018 s | 16.3% |
| `FLASH_ATTN_EXT` | 432.931 s | 319.551 s | 26.2% |
| Operations containing `MUL_MAT` | 204.440 s | 204.341 s | 0.05% |
| Other operations | 59.387 s | 59.125 s | 0.4% |

Traced Q8 decode time was 0.817 s for ten tokens in both runs; the production Q8 decode path uses vector attention and was not changed by this selection. The candidate used the stock matrix path in this run, isolating the attention effect. The matching matrix and other times support attention as the source of the prefill gain. This is a **16.3% direct full-chunk prefill improvement** against the saved stock path, above the 10% target. It is not yet a combined custom-matrix-engine or endpoint result, and `llama-bench` did not compare generated output content.
