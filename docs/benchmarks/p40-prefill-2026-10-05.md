# Tesla P40 direct PQ2 prefill baseline, 2026-10-05

The Tesla P40 is SM61 with 23,040 MiB reported GPU memory. The isolated SM61
`test-backend-ops` binary was built on `.30` and staged on `.40`; the production
endpoint was untouched. This is a direct operator baseline, not a full-model
or long-context measurement.

| PQ2 × F32 shape (M × N × K) | Stock Bonsai |
| --- | ---: |
| 17408 × 2048 × 5120 | 21.913 ms |
| 5120 × 2048 × 17408 | 22.289 ms |

The [dispatch log](p40-prefill-2026-10-05-evidence/merlin-prefill-sm61-stock-kernel.log)
records 256 Prism selections, 256 unsupported-custom bypasses, and no CUTLASS
selection. The current custom prefill is a Tensor Core path and cannot run on
SM61. The original design specifies that path for the RTX 8000 and RTX 3090;
it does not define a P40 prefill kernel. A separate packed PQ2/Q8 DP4A
candidate is pending an owner decision. There is no custom P40 performance
claim yet. The [direct timing log](p40-prefill-2026-10-05-evidence/merlin-prefill-sm61-stock-perf.log)
is retained with this note.
